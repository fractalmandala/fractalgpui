# pibots design assets

Carried over when the pibots Rust UI was retired (stage 7).

- `icons/`: the 1000-icon set from pibots `public/icons`.
- `bots/`: the bot avatar images from pibots `public/bots`.
- `tokens/`: the pibots color values (light/dark palettes, roles, shadows, motion, control and layout sizes) as the original Rust source, for reference. Not wired into the Sass tokens yet.
